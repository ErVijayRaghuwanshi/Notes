# Notes

This repository is a collection of technical notes and quick reference documents I keep while working with embedded systems, FastAPI, API gateways, design principles, and related topics. The files are short-form guides, how-tos, and reference material intended for quick lookup.

## Repository contents

- [DHTExporter.md](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/DHTExporter.md) — Notes about exporting DHT sensor data and tooling for collecting metrics.
- [Database Design.md](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/Database%20Design.md) — Database design patterns, normalization tips, and ER modelling notes.
- [ESP8266 DHT11.md](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/ESP8266%20DHT11.md) — Practical notes and example code for using DHT11 sensors with ESP8266 microcontrollers.
- [FastAPI_Middleare.md](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/FastAPI_Middleare.md) — Middleware patterns and implementation notes for FastAPI applications.
- [FastAPI_RBAC.md](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/FastAPI_RBAC.md) — Role-Based Access Control (RBAC) approaches and examples for FastAPI.
- [Kong API Gateway 101.md](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/Kong%20API%20Gateway%20101.md) — Introductory notes on using Kong as an API gateway and plugin ecosystem.
- [SOLID.md](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/SOLID.md) — Summary and examples of the SOLID design principles.
- [fastapi-k8s.md](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/fastapi-k8s.md) — Deployment notes for running FastAPI apps on Kubernetes.
- [Makefile](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/Makefile) — Build and convenience targets used while working with these notes.
- [LICENSE](https://github.com/ErVijayRaghuwanshi/Notes/blob/main/LICENSE) — Project license.
- spark/ — Directory with notes or scripts related to Apache Spark (see the repository tree).

## How to use

- Browse files directly on GitHub by clicking the links above.
- Clone the repository to search or edit notes locally.

  git clone https://github.com/ErVijayRaghuwanshi/Notes.git

- Use the Makefile targets for any convenience tasks included in the repository (see `Makefile` for details).
