## 🎯 Interview Timeline

### 4 Weeks Before
- [ ] Review all core CS fundamentals
- [ ] Practice 2-3 LeetCode problems daily
- [ ] Read [system design case studies](../SystemDesign/15-case-studies/README.md)
- [ ] Prepare behavioral stories (STAR format)

### 2 Weeks Before
- [ ] Mock interviews (technical + behavioral)
- [ ] Review company-specific questions
- [ ] Practice whiteboard coding
- [ ] Prepare questions for interviewer

### 1 Week Before
- [ ] Review quick reference sheets
- [ ] Practice common patterns
- [ ] Light problem solving (confidence building)
- [ ] Rest and mental preparation

### Day Before
- [ ] Review your resume and projects
- [ ] Prepare setup (laptop, whiteboard, markers)
- [ ] Get good sleep
- [ ] Prepare questions for interviewer

## 💡 Interview Types

### Technical Screen (45-60 min)
- 1-2 coding problems
- Focus on correctness and optimization
- Explain your thought process
- Test your code with examples

### System Design (45-60 min)
- Design a scalable system
- Discuss trade-offs
- Handle follow-up questions
- Draw architecture diagrams

### Behavioral (30-45 min)
- Past experiences and projects
- Leadership and teamwork
- Handling conflicts
- Learning from failures

### Coding Onsite (Multiple rounds)
- Data structures & algorithms
- Problem-solving approach
- Code quality and testing
- Communication skills

## 🏗️ Preparation Strategy

### Technical Skills
1. **Data Structures**: Master arrays, trees, graphs, hash tables
2. **Algorithms**: Practice sorting, searching, DP, greedy
3. **System Design**: Study scalability, databases, caching
4. **Domain Knowledge**: Backend, big data, or full-stack

### Soft Skills
1. **Communication**: Explain clearly and concisely
2. **Problem-Solving**: Break down complex problems
3. **Collaboration**: Show teamwork examples
4. **Learning**: Demonstrate growth mindset

### Company Research
1. **Products**: Understand what they build
2. **Tech Stack**: Know their technologies
3. **Culture**: Read about values and principles
4. **Recent News**: Stay updated on company developments

## 📊 Common Mistakes to Avoid

### Technical
- ❌ Not clarifying requirements before coding
- ❌ Jumping to code without planning
- ❌ Not testing with edge cases
- ❌ Poor variable naming
- ❌ Not discussing time/space complexity

### Behavioral
- ❌ Not using STAR format
- ❌ Being too vague or too detailed
- ❌ Not showing impact of your work
- ❌ Blaming others for failures
- ❌ Not preparing questions for interviewer

### System Design
- ❌ Not asking clarifying questions
- ❌ Jumping to implementation details
- ❌ Ignoring trade-offs
- ❌ Not discussing failure scenarios
- ❌ Over-engineering for small scale
